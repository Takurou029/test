# 自分磨きRPG - 習慣化アプリ

日々の習慣をRPG風にゲーム化して、自己成長を楽しく継続できるWebアプリケーションです。

## 主な機能

### 🎮 RPG要素
- **レベルシステム**: タスクを完了して経験値を獲得し、レベルアップ
- **ステータス**: 筋力、知性、精神、体力、魅力の5つのステータス
- **カテゴリ別成長**: タスクのカテゴリに応じて対応するステータスが成長

### ✅ タスク管理
- **自由なタスク作成**: 自分の目標に合わせたタスクを設定
- **カテゴリ分類**: 運動、学習、精神、健康、身だしなみ、社交、創作、その他
- **難易度設定**: 3段階の難易度で獲得経験値が変化
- **毎日のタスク**: 日課として設定可能
- **リマインダー**: タスクの実行時刻を設定（通知機能は今後実装予定）

### 📊 進捗可視化
- **連続達成日数**: 毎日の継続をストリーク機能でモチベーション維持
- **統計情報**: 総完了数、カテゴリ別の完了数を確認
- **レベルアップアニメーション**: 成長を視覚的に実感

### 💾 データ保存
- LocalStorageでデータを保存（ブラウザローカル）
- データのリセット機能

## 技術スタック

- **React 19** + **TypeScript**: モダンなUI構築
- **Vite**: 高速な開発環境
- **Tailwind CSS**: スタイリング
- **LocalStorage**: クライアントサイドデータ永続化

## 使い方

1. **タスクを作成**: 「タスクを追加」ボタンから新しいタスクを作成
2. **タスクを完了**: チェックボックスをクリックしてタスクを完了
3. **経験値獲得**: タスク完了で経験値とステータスが増加
4. **レベルアップ**: 経験値が一定値に達するとレベルアップ！
5. **統計確認**: 「統計情報」タブで自分の成長を確認

## RPGシステムの詳細

### 経験値とレベル
- タスク完了時に経験値を獲得
- 獲得経験値 = 難易度 × 10
  - 簡単: 10 EXP
  - 普通: 20 EXP
  - 難しい: 30 EXP
- レベルアップに必要な経験値は指数関数的に増加

### ステータス成長
- **レベルアップ時**: 全ステータス +1
- **タスク完了時**: カテゴリに応じたステータス + 難易度値

| カテゴリ | 対応ステータス |
|---------|--------------|
| 運動・筋トレ | 筋力 💪 |
| 学習・スキル | 知性 🧠 |
| 瞑想・メンタル | 精神 🧘 |
| 健康習慣 | 体力 ❤️ |
| 身だしなみ | 魅力 ✨ |
| 社交 | 魅力 ✨ |
| 創作活動 | 知性 🧠 |
| その他 | 体力 ❤️ |

### 連続達成（ストリーク）
- 毎日タスクを完了することでストリークが増加
- 1日でもタスクを完了しない日があるとリセット
- 最長記録も保存されるため、モチベーション維持に活用
