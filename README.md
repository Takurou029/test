# 四つ角や ホームページ

富士吉田市大明見のパン屋「四つ角や」向けの静的ホームページです。
`index.html` と `styles.css` だけで表示できるため、サーバーにアップロードするだけで公開できます。

## プレビュー方法

このリポジトリのルートで以下を実行してください。

```bash
npm run preview
```

起動後、ブラウザで次のURLを開くとプレビューできます。

```text
http://localhost:4173/
```

Node.js/npmを使わずに確認したい場合は、以下でも同じように起動できます。

```bash
python3 -m http.server 4173
```

終了するときは、ターミナルで `Ctrl + C` を押してください。

## 確認コマンド

HTMLの簡易チェックは以下で実行できます。

```bash
npm run check:html
```
